# Shruti 1.0.8.0

This release adds a local transcription library and improves dictation controls.

- Transcriptions is the opening page, with search, copy, original/final text, and deletion controls.
- Insights summarizes saved dictations. Dictionary supports personal vocabulary and exact corrections. Snippets expand spoken phrases into saved text.
- Transcript formatting and optional local AI cleanup preserve the original text for recovery. The AI model is an optional download.
- Speech detection prevents silent recordings from adding invented words.
- The floating bar can appear on one selected monitor or all monitors.
- Dropdowns have opaque backgrounds in light and dark themes, and filter controls align consistently.
- The separate Dictation page is removed. Shortcuts, the tray, and floating bars start dictation. Pending previews appear in Transcriptions.

History, dictionary entries, snippets, and settings remain on your computer.
History starts with this version; earlier dictations are not recreated. Delete
individual transcripts or clear history on the Transcriptions page.

The self-contained x64 ZIP is for Scoop, WinGet, or manual extraction. Start
`Shruti/Shruti.App.WinUI.exe`. The executable is unsigned. Microsoft Store
installation uses Microsoft's signing and update system. The unsigned MSIX is
for Partner Center submission, not direct installation.

Windows 10 build 19041 or later is required. Speech and optional cleanup models
download separately. Models are not included except the small speech detector.

Validation includes the full 319-test suite, package content and native runtime
checks, and isolated rendering tests for dropdowns. Full interactive coverage
across all applications and monitor configurations remains manual. No general
accuracy or competing-product parity claim is made.
